# Пространство красоты

Одностраничный промосайт пространства красоты с адаптивной вёрсткой, анимацией появления текста и интерактивным окном записи.

## Структура

- `dist/index.html` — основная страница;
- `dist/beauty-space-hero.css` — стили и анимации;
- `dist/beauty-space-hero.js` — интерактивность;
- `dist/assets/` — изображения.

Откройте `dist/index.html` в браузере для локального просмотра.
