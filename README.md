# Пространство красоты

Мобильный одностраничный сайт врача-косметолога Яны Милос с адаптивной вёрсткой, анимацией появления текста, записью по городам и модальными окнами услуг.

## Структура

- `dist/index.html` — разметка страницы;
- `dist/yana-milos.css` — стили и анимации;
- `dist/yana-milos.js` — контакты и интерактивность;
- `dist/assets/` — используемые изображения;
- `.github/workflows/pages.yml` — публикация на GitHub Pages.

Откройте `dist/index.html` в браузере для локального просмотра.

Опубликованная версия: https://kirillartdesign.github.io/milos-beauty-space/
